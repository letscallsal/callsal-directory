Iconify is an aggregator for open source icon sets. You search once, across Material, Remix, Fluent, Simple Icons, emoji sets, and the rest. The icons are validated, cleaned up, and published in one shared format so they can be used the same way.

It is for the person making an interface who needs a home, a chevron, or a brand mark and does not want to install a new pack for every job. Designers can browse the official icon-sets site and paste SVG, or use the Figma or Sketch plugin. Developers can use a web component, add icons to CSS, or load icon data from the public API.

The project is free and open source. Official docs put the count at over 300,000 icons from more than 200 sets, updated several times a week. Almost all Iconify packages use the MIT license. That license does not cover the icons. Sets use Apache, OFL, CC BY, and others. Some ask for attribution. The browse site lists each set with its license.

The limit is that this is a layer, not a style. You still choose a set, and you still read that set license. On-demand components need the API, or a host you run. If you already standardized on one pack, you do not need this.

Use it when you want one search across the open icon world. Skip it when you already have a library and a license you trust.
